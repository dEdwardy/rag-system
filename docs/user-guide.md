# RAG 系统使用手册

> 文档角色：`user-guide`
> 适用对象：日常使用本系统管理资料、提问、检查回答质量和排查问题的用户。
> 更新时间：2026-11-01

这份手册按“第一次使用”到“日常排障”的顺序说明页面和功能。开发、部署和接口细节不在这里展开，相关文档见文末。

## 1. 系统是做什么的

这个系统围绕一个“工作区资料库”工作：

1. 把文件或链接加入当前资料库。
2. 系统解析、切片、生成 embedding 并建立索引。
3. 对话页会先检索相关资料，再基于检索结果生成带引用的回答。
4. 每次回答都会留下诊断记录，方便检查检索、引用和生成过程。
5. 质量报告可以固定一组问题，反复运行并比较回答质量是否回退。

可以把它理解成：**资料入库 -> 检索问答 -> 引用与诊断 -> 质量回归**。

## 2. 第一次使用：五步跑通

### 第一步：登录

打开系统后，按页面提示登录：

- 本地账号：填写邮箱和密码。
- 外部账号：如果管理员已经配置，可使用 GitHub、Google 或 OIDC 登录。
- 如果出现邀请码页面，需要先输入管理员提供的邀请码。

登录后默认进入“对话”页。

### 第二步：创建或确认工作区资料库

进入左侧导航的 **工作区设置**（`/knowledge-base`）：

- 如果当前没有资料库，点击 **创建工作区资料库**。
- 填写名称和可选描述。资料、对话、回答设置都会围绕这个资料库工作。
- 创建完成后，页面会提示下一步去添加资料。

工作区设置页还会显示：

- 已就绪资料、更新中资料、有问题的资料、已连接助手数量。
- 当前工作区快照和推荐的下一步操作。
- **刷新默认路径**：当默认助手或默认链路没有自动出现时，用它重新检查。

### 第三步：添加第一批资料

进入 **资料库**（`/documents`），可以添加四类来源：

| 来源类型 | 操作                    | 适用场景                                    |
| -------- | ----------------------- | ------------------------------------------- |
| 文件     | 点击上传或直接拖拽文件  | PDF、DOCX、Markdown、TXT、JSON 等文本型资料 |
| 网页     | 粘贴一个 `http(s)` 链接 | 单篇文章、文档页、说明页                    |
| 订阅源   | 粘贴 RSS / Atom 链接    | 博客、新闻、持续更新的栏目                  |
| 站点地图 | 粘贴 sitemap 链接       | 整站或某个栏目批量同步                      |

添加后，资料会经历类似下面的状态：

- `pending`：排队中。
- `processing`：解析、切片或索引中。
- `ready`：已就绪，可以被检索和提问。
- `failed`：处理失败，需要查看错误摘要后重试或删除。

资料还在处理中时，已就绪的旧资料仍然可以支持对话，但回答不一定包含最新内容。

### 第四步：确认回答设置

进入 **回答设置**（`/assistant`）：

- 大多数场景保持推荐默认值即可。
- 推荐默认：`balanced` 回答风格、必须引用、上下文不足时明确说明、提示还缺哪些信息。
- 推荐检索默认：`topK 3`、`chunk window 0`、关闭 hybrid、关闭 rerank。

只有当你明确遇到“回答漏内容”或“检索噪声太多”时，再调整高级检索设置。

### 第五步：开始提问

回到 **对话**（`/`），在输入框里输入问题并按 Enter。首次提问会自动创建会话。

如果输入框不可用，优先检查：

1. 当前工作区是否已经创建资料库。
2. 资料库里是否至少有一个 `ready` 资料。
3. 默认助手是否已经准备好；如果没有，回工作区设置点击 **刷新默认路径**。

## 3. 页面地图

左侧导航分为三组：

| 分组   | 页面       | 路径              | 用途                                  |
| ------ | ---------- | ----------------- | ------------------------------------- |
| 使用   | 对话       | `/`               | 提问、查看引用、查看 Agent 步骤、反馈 |
| 使用   | 资料库     | `/documents`      | 上传文件、添加链接、查看资料状态      |
| 设置   | 工作区设置 | `/knowledge-base` | 创建/确认资料库，查看工作区健康状况   |
| 设置   | 回答设置   | `/assistant`      | 配置回答风格、引用和检索行为          |
| 工作台 | 概览       | `/workbench`      | 运行、质量和诊断入口的汇总页          |
| 工作台 | 诊断       | `/traces`         | 按会话查看回答 trace                  |
| 工作台 | 运行概览   | `/usage`          | 资料运行健康、异常趋势、LLM 用量      |
| 工作台 | 质量报告   | `/reports`        | 题集、baseline、质量检查和回归分析    |

“工作台”分组默认是折叠的。日常使用通常只需要“对话”和“资料库”；排障和评估时再展开。

## 4. 资料库使用说明

### 4.1 添加文件

在资料库页面上方点击上传按钮，或把文件拖到上传区域：

- 支持一次选择多个文件。
- 上传成功只表示文件已保存，不代表已经可以被检索。
- 需要等到状态变成 `ready`，资料才真正进入问答链路。

### 4.2 添加网页、订阅源和站点地图

在“添加来源”区域分别填写 URL：

- **网页**：只抓取这一个页面。
- **订阅源**：解析 RSS / Atom，并同步其中的条目。
- **站点地图**：解析 sitemap，并按配置同步其中的页面。

保存后到下方资料列表查看状态。外部来源抓取可能因为网络、站点限制或安全策略失败，错误会显示在资料详情里。

### 4.3 资料详情页

点击某个资料进入详情页（`/documents/:documentId`），可以查看：

- 资料主状态、处理阶段和下一步建议。
- 最近一次运行摘要。
- 切片列表和切片内容。
- 存储键、错误信息等次级诊断信息。
- 资料运行记录：上传、重新索引、外部同步的历史。
- 从 trace 跳转过来的聚焦切片；如果是从诊断页进入，可直接返回原 trace。

### 4.4 重新索引和删除

- **重新索引**：资料内容或解析结果需要重建时使用。会重新走解析、切片和索引。
- **删除**：永久移除当前资料记录。失败资料确认不再需要时可以删除。

重新索引不会改变资料 ID，但会生成新的运行记录。删除前请确认没有正在使用它的对话或评估。

## 5. 工作区设置

工作区设置页负责“当前工作区资料库”的状态，不负责单篇资料操作。

重点看三块：

1. **工作区快照**：资料数、切片数、已连接助手数。
2. **指标卡**：已就绪、更新中、需要处理、已连接助手。
3. **下一步建议**：系统会根据当前状态给出最合适的动作，例如先加资料、先处理失败资料、等待更新完成或直接进入对话。

如果默认助手没有自动出现：

1. 确认资料库里已经有资料。
2. 点击 **刷新默认路径**。
3. 等待助手出现后再去回答设置或对话页。

## 6. 回答设置

回答设置页分为三层，建议从上到下理解。

### 6.1 回答应该如何呈现

- **回答风格**：简洁、平衡、详细。
- **语气**：中性、友好、直接。
- **输出格式**：段落、要点列表、Markdown。
- **语言**：自动、跟随提问语言、中文、英文。
- **来源引用**：必须引用或可选引用。
- **最大引用数**：控制回答最多引用几个来源。
- **上下文不足时**：明确说明上下文不足，或尽力回答。
- **补充说明还缺什么信息**：开启后会告诉用户还缺哪些信息。

推荐保持：`balanced + 必须引用 + 明确说明上下文不足 + 提示缺失信息`。

### 6.2 检索行为

- **topK**：每次检索取多少个切片。
- **chunk window**：命中切片是否带相邻切片。
- **score threshold**：低于阈值的检索结果是否丢弃。
- **混合检索**：向量检索和关键词检索一起用。
- **rerank**：回答前对候选结果重新排序。

默认值通常更稳定。调大 topK 会增加上下文和成本；调高阈值可能减少噪声，但也可能漏掉正确内容。

### 6.3 高级检索策略和范围限制

高级区域可以覆盖默认检索策略：

- 检索模式：向量、混合、关键词。
- 候选倍数、最小候选数。
- 混合检索的向量权重和关键词权重。
- 检索前是否改写问题。
- 是否使用策略级 rerank 覆盖。

范围限制可以把检索限制在：

- 指定或排除的 document ID。
- 指定或排除的章节标题。
- 章节标题包含某些关键词。
- 指定或排除的页码，以及最小/最大页码。

列表字段支持逗号或换行分隔。全部清空并保存后，会移除已保存的范围限制。

## 7. 对话

### 7.1 会话管理

- 点击 **新建对话** 开始一个新会话。
- 左侧历史记录可以切换已有会话。
- 会话可以重命名。
- 删除会话会保留消息但归档该会话，不再出现在常用历史里。

### 7.2 提问

- Enter 发送。
- Shift + Enter 换行。
- 输入框上方的首问按钮会直接发送一个示例问题。
- 回答流式生成时，可以点击停止。
- 回答完成后可以复制、重新生成、打开诊断或提交反馈。

### 7.3 普通模式和 Agent 模式

输入区右上角有 **Agent 模式** 开关：

- 普通模式：一次检索 + 生成回答，速度更快，适合大多数直接问题。
- Agent 模式：执行受控的多步检索计划，并实时展示步骤，适合比较复杂的问题。

Agent 模式常见步骤：

| 步骤     | 含义                                         |
| -------- | -------------------------------------------- |
| 路由判断 | 判断问题属于知识库问答、策略回复还是外部来源 |
| 主检索   | 先检索当前资料库                             |
| 证据检查 | 判断首轮证据是否足够                         |
| 补充检索 | 证据不足或问题复杂时，生成新的查询再查一次   |
| 生成回答 | 基于合并后的证据生成最终回答                 |

Agent 模式会增加耗时，但能展示过程，也更容易发现“检索没找到”还是“回答没用好证据”。

### 7.4 引用和诊断

回答里的 `[1]`、`[2]` 等标记对应右侧来源列表。点击引用可以查看来源片段。

每个回答可以：

- **打开诊断**：进入这次回答的 trace 详情。
- **重新生成**：用同一个问题重新回答。
- **复制**：复制回答正文。
- **反馈**：对回答点“有帮助”或“没帮助”。当前前端只提交这两个评级。

### 7.5 长会话和断线

- 长会话默认先显示最近 80 条消息，顶部可以加载更早的消息。
- 流式回答如果中途断线，客户端会自动尝试带上 `Last-Event-ID` 续传。
- 如果续传失败，可以重新生成，或重新提问。

## 8. 诊断

诊断页用于回答不符合预期时排查。

### 8.1 诊断列表（`/traces`）

按会话展示最近一次 trace，可以先看：

- 用户问题。
- 最近结果：成功、需要检查或失败。
- 模型。
- 首个 token 耗时、回答生成耗时、检索耗时。

点击进入 trace 详情。

### 8.2 Trace 详情

Trace 详情通常包含：

- 原始问题和真正用于检索的问题。
- 是否发生查询改写。
- 检索到的切片、分数、排名、主切片/邻接切片、是否被引用。
- 引用列表。
- 路由决策、执行模式、工具名和执行步骤。
- Agent 执行步骤；如果本次是 Agent 模式，会单独展示。
- 模型、总耗时、首 token 耗时和错误信息。

建议排查顺序：

1. 先看回答状态和错误信息。
2. 再看检索是否命中了正确切片。
3. 如果命中不对，检查查询改写、检索模式和 topK。
4. 如果命中正确但回答不好，检查引用和回答设置。
5. 如果回答很慢，查看首 token 和检索耗时。

## 9. 运行概览

运行概览（`/usage`）用于看整个资料库和运行链路的健康状况。

可以切换时间范围：1 小时、6 小时、24 小时、3 天、7 天。

主要模块：

- **指标卡**：资料库、资料、切片、助手、会话、已就绪资料。
- **资料运行健康**：处理中、失败、可重试失败、不可重试失败、边界命中。
- **异常趋势和告警**：按时间窗口聚合问题。
- **LLM 用量与首 token**：采样 trace 数、首 token P50/P95、总耗时 P50/P95、token 总量、估算成本、按模型分布。
- **审计事件**：trace 和资料运行的近期事件。

成本估算需要管理员配置输入/输出 token 单价，否则成本显示为 0。tokens 如果来自估算而不是 provider 返回值，页面会显示“tokens 为估算值”。

## 10. 质量报告

质量报告（`/reports`）用于把一组固定问题反复跑，检查回答质量是否下降。

### 10.1 准备题集和 baseline

1. 选择一个已有题集，或创建一个新题集。
2. 新题集需要填写名称、说明和问题列表；问题可以逐条添加。
3. 首次使用时，为当前题集生成一个 **baseline snapshot**。
4. baseline 代表后续比较的基准。后续运行可以选择某个 baseline 做回归对比。

### 10.2 运行质量检查

选择：

- 题集。
- assistant。
- 可选 baseline snapshot。

运行后，结果会进入结果表和右侧分析面板。

### 10.3 看结果

结果表支持按以下维度筛选：

- 状态：成功、失败等。
- 质量：strong、partial、weak。
- 复核状态：待复核、已复核。
- 结论：检索问题、引用问题、回答问题、暂不处理。

每一行可以看到：

- 问题、回答状态、质量、主要问题。
- 引用数量。
- 诊断/问题提示。
- 打开诊断的链接。

### 10.4 复核

对每一行可以：

- 标记为已复核，或退回待复核。
- 填写结论：检索问题、引用问题、回答问题或暂不处理。

复核状态保存在浏览器本地，适合个人逐轮检查。

### 10.5 分析和导出

分析面板会展示：

- 质量分布。
- 与 baseline 的差异和回归原因。
- 质量门禁结果和触发的指标。
- 失败和超时的重点排查入口。

导出支持：

- Markdown 报告。
- JSON 报告。
- HTML 报告。
- 复核摘要（Markdown）。

## 11. 常见工作流

### 11.1 新资料入库并验证

1. 资料库上传文件或添加链接。
2. 等待状态变成 `ready`。
3. 对话里问一个能直接从该资料回答的问题。
4. 打开诊断，确认检索命中了目标切片，并且回答引用了它。

### 11.2 回答不准时排查

1. 先看回答是否“上下文不足”。
2. 打开诊断，看检索切片是否正确。
3. 如果检索错误，检查查询改写、检索模式、topK 和范围限制。
4. 如果检索正确但回答不好，检查回答风格、引用设置和 system prompt。
5. 如果问题复杂，尝试开启 Agent 模式再问一次。

### 11.3 做一次质量回归

1. 进入质量报告。
2. 选择题集和 baseline。
3. 运行质量检查。
4. 看质量分布和回归 diff。
5. 对失败或回退项逐个复核并填写结论。
6. 导出报告或复核摘要。

### 11.4 查看运行健康和成本

1. 进入运行概览。
2. 选择时间范围。
3. 先看失败数和处理中数量。
4. 再看 LLM 用量卡片里的首 token P95、总耗时 P95 和 token 总量。
5. 如果成本显示为 0，说明还没有配置 token 单价。

## 12. 常见问题

### 为什么输入框不可用？

通常是以下原因之一：

- 当前工作区还没有资料库。
- 资料库里没有 `ready` 资料。
- 默认助手还没有准备好。
- 后端暂时不可达。

按页面提示先创建工作区资料库、添加资料，或点击“刷新默认路径”。

### 为什么资料一直显示处理中？

处理中包括解析、切片和索引。PDF 或较大的网页可能需要更长时间。先等待一轮；如果长时间不结束，打开资料详情查看最近一次运行记录和错误。

### 为什么回答说上下文不足？

常见原因：

- 资料库里没有相关资料。
- 资料还没有 `ready`。
- 检索阈值过高或 topK 太小。
- 问题太宽泛，和资料表述差异太大。
- 范围限制排除了相关资料。

可以先看诊断里的检索切片，再决定是补资料、改问题，还是调检索设置。

### 引用编号怎么对应？

回答里的 `[1]`、`[2]` 对应右侧“来源”列表的顺序。点击引用会打开对应切片。

### Agent 模式什么时候用？

适合：

- 问题需要跨多个文档或章节。
- 问题需要先查一次再补充查一次。
- 你想看到检索和证据判断过程。
- 追问依赖上下文，普通模式容易丢失指代。

简单事实问题建议先用普通模式。

### 反馈有什么用？

反馈会记录到后端，用于后续质量分析和改进。当前版本不会自动把负反馈转成 eval 题；后续可以再补“一键加入题集”的工作流。

### 为什么某些网页添加失败？

外部链接会经过安全校验和抓取限制。私网地址、localhost、云 metadata 地址、被允许列表排除的域名，或站点本身拒绝抓取，都可能失败。管理员可以通过 `SOURCE_FETCH_ALLOWED_HOSTS` 配置允许的域名范围。

### 删除会话会删除消息吗？

不会立即删除消息。删除会话主要是归档该会话，让它不再出现在常用历史里。需要彻底清理时请使用数据维护流程。

### 成本为什么是 0？

运行概览里的成本估算依赖管理员配置的 token 单价。未配置时只展示 token 数量，成本为 0。

### 怎么切换中英文或退出登录？

侧边栏或移动端菜单顶部有中文/英文切换按钮。当前身份信息区域提供退出登录入口。

## 13. 术语表

| 术语            | 说明                                                   |
| --------------- | ------------------------------------------------------ |
| 工作区资料库    | 当前工作区共享的资料目标，资料、对话和回答设置都围绕它 |
| 资料项          | 一个文件、网页、订阅源或站点地图同步结果               |
| 切片 / chunk    | 资料被切分后的可检索文本片段                           |
| embedding       | 用于向量检索的文本向量                                 |
| topK            | 每次检索返回的切片数量                                 |
| chunk window    | 命中切片时额外带上的相邻切片                           |
| score threshold | 低于该分数的检索结果会被丢弃                           |
| hybrid          | 向量检索和关键词检索混合                               |
| rerank          | 对候选切片重新排序                                     |
| trace           | 一次回答的完整诊断记录                                 |
| baseline        | 质量报告用于回归比较的历史基准                         |
| 质量门禁        | 用阈值判断本轮质量是否达标                             |
| Agent 模式      | 带步骤展示和受控二次检索的问答模式                     |
| 兜底 / fallback | 模型不可用或输出不可解析时使用的本地回答逻辑           |
