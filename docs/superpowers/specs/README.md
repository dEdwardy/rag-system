# Superpowers Specs Guide

> 文档角色：`archive-index`
> 当前使用方式：本目录保存任务级 design/spec 记录，主要用于历史参考、同类任务复用和补充上下文，不作为当前阶段优先级主入口。

## What This Folder Is

This folder stores bounded task design records created during implementation rounds.

## How To Use It

Use a spec file when:

- the current task directly matches an existing design record
- you want the original scope, goals, non-goals, and acceptance criteria for a past increment
- you are creating a new task-scoped design record

Do not use this folder as the only source for:

- current top priority
- current-stage workflow policy
- current AI review policy

Those are currently defined by:

- [docs/next_steps_rag_project_plan.md](/D:/FeProjects/rag-system/docs/next_steps_rag_project_plan.md)
- [docs/current-progress.md](/D:/FeProjects/rag-system/docs/current-progress.md)

## Practical Rule

If a spec conflicts with the current-stage top-level docs, treat the spec as historical task context unless it is being explicitly reused for the current task.
