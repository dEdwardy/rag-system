# Superpowers Docs Guide

> 文档角色：`archive-index`
> 当前使用方式：这是 `docs/superpowers/` 的任务档案导航，不是当前阶段优先级主入口。

This folder stores task-scoped design and implementation records.

It is not the primary daily entry point for deciding current project priority.

## Structure

- `specs/`
  - design notes for a bounded task or increment
- `plans/`
  - implementation checklists/plans for a bounded task or increment

## How To Use This Folder

Use these files when:

- the current task directly matches an existing spec/plan
- you need historical context for a completed increment
- you are creating a new bounded task record

Do not use this folder as the only source for:

- current top priority
- current-stage superpowers policy
- current AI review policy

Those decisions are currently defined in:

- [docs/next_steps_rag_project_plan.md](/D:/FeProjects/rag-system/docs/next_steps_rag_project_plan.md)
- [docs/current-progress.md](/D:/FeProjects/rag-system/docs/current-progress.md)

## Naming Intent

Most files in this folder are historical task records from a specific implementation round.

Treat them as:

- useful references
- implementation archives
- task-specific context

Not as a replacement for the top-level docs guide.
