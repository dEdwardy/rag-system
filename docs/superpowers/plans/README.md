# Superpowers Plans Guide

> 文档角色：`archive-index`
> 当前使用方式：本目录保存任务级 implementation plan 记录，主要用于历史参考、复用和补充上下文，不作为当前阶段优先级主入口。

## What This Folder Is

This folder stores bounded task implementation plans from specific development rounds.

## How To Use It

Use a plan file when:

- the current task directly matches an existing plan
- you want the original implementation steps and verification commands for a past increment
- you are creating a new task-scoped implementation plan

Do not use this folder as the only source for:

- current top priority
- current-stage superpowers usage style
- current AI review policy

Those are currently defined by:

- [docs/next_steps_rag_project_plan.md](../../next_steps_rag_project_plan.md)
- [docs/current-progress.md](../../current-progress.md)

## Practical Rule

If a plan describes a completed increment, treat it as a historical implementation record unless the current task explicitly reuses it.
