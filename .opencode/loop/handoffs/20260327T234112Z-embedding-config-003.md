### Exact configuration risk reduced
This removes a config drift risk where:
- chat/rewrite already points to a proxy/compatible endpoint via `OPENAI_BASE_URL`,
- but embeddings still used hardcoded hosted OpenAI endpoint.

With this fix, embedding endpoint now follows the same base URL defaulting path, reducing:
- accidental cross-endpoint mismatch,
- unexpected fallback due unreachable hosted endpoint,
- unintended egress/cost/compliance surprises in proxy-based deployments.
